# Todo App (React + Vite)

A simple and responsive Todo application built using React and Vite.  
This project helps users manage daily tasks efficiently with an easy-to-use interface.

---

## 🚀 Live Demo
👉 https://yesharah31.github.io/Todo/

---

## 📌 Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Real-time UI updates
- Responsive design for all devices

---

## 🛠️ Tech Stack

- React
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- GitHub Pages (Deployment)
